# Experimental Results

This directory contains the machine-readable experimental results generated by the SCADA XAI IDS research pipeline.

The results correspond to the baseline, GAN augmentation, controlled robustness, perturbation-aware training, SHAP explainability, multi-seed evaluation, ablation, and robustness-delta experiments.

The raw WUSTL-IIOT-2018 dataset is not included in this repository.
